# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 3.x     | ✅ Yes     |
| 2.x     | ⚠️ Security fixes only |
| < 2.0   | ❌ No      |

## Reporting a vulnerability

Email security@healthdata.example.com with subject "VULNERABILITY REPORT".
Do NOT open a public GitHub issue.

**Response SLA:** Acknowledge within 24h; triage within 72h.

## PHI incidents

If you discover a potential PHI breach, treat as P0. See docs/runbooks/incident-response.md.
