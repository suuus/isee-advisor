# HealthData Platform

HIPAA-covered health data exchange service. Processes PHI for 200+ covered entities.

## Outcomes

1. Zero PHI leaks — all data encrypted at rest and in transit
2. 99.9% uptime SLA with < 4hr RTO
3. SOC 2 Type II certification maintained annually
4. All access to PHI audited and attributable
5. Breach notification within 72 hours of detection
