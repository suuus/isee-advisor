# Tasks API

A simple REST API for managing tasks. Built for a 3-person startup that needed something faster than Trello.

## What we're building

A no-frills task manager that:
- Loads under 100ms on slow connections
- Lets users invite teammates by email
- Syncs offline edits when they reconnect

## Tech

- Node 20 + Fastify
- Postgres
- Vite for the web client

## Getting started

```
npm install
npm run dev
```

## Status

Early prototype. We're shipping daily to a closed beta of 8 design partners. Feedback drives the next sprint.
