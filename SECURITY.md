# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public issue.**

Instead, please use [GitHub's private vulnerability reporting](https://github.com/suuus/isee-advisor/security/advisories/new) to submit your report.

### What to Include

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Any relevant logs, screenshots, or proof-of-concept.

### What to Expect

- **Acknowledgment** within 5 business days.
- We will work with you to understand and validate the issue.
- A fix will be developed and released as quickly as possible.
- You will be credited in the release notes (unless you prefer otherwise).

## Scope

This policy applies to the ISEE Advisor codebase and its published GitHub Copilot plugin artifacts. Third-party dependencies are outside the direct scope of this policy but will be triaged if reported.

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |
| Older   | ❌        |

We recommend always using the latest version.
